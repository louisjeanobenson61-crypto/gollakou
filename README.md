# GOLLAKOU — vèsyon demaraj pou GitHub

Sa a se yon sit/app web PWA ki fèt pou telefòn. Li gen Akèy, Match, Pronostik, Meyè chwa, Nouvèl ak Konfigirasyon.

## Mete sou GitHub Pages
1. Sou GitHub, kreye yon repository ki rele `gollakou`.
2. Louvri ZIP la sou telefòn ou epi telechaje fichye ki ladan l nan repository a (pa mete ZIP la kòm sèl fichye).
3. Peze **Commit changes**.
4. Ale nan **Settings → Pages**.
5. Chwazi **Deploy from a branch**, branch `main`, folder `/(root)`, epi sove.
6. Tann adrès sit la parèt.

## Match reyèl
Match yo sèvi ak Football-Data.org API. Kreye kont, verifye plan ak konpetisyon ki disponib, pran API token an, epi mete li nan **Konfigirasyon**. Pa mete token an nan kòd piblik GitHub. Vèsyon sa a se pou tès sou navigatè; pou piblikasyon serye, sèvi ak yon backend pou pwoteje kle API a.

## Nouvèl
App la eseye chaje RSS BBC Sport ak The Guardian atravè RSS-to-JSON. Sous ekstèn yo ka pa disponib tout tan; nouvèl yo gen lyen pou sous orijinal la.

## Limit enpòtan
- Sa se yon sit/app web PWA, **li poko yon APK oswa AAB Google Play**.
- Pa gen pronostik envante. Paj pronostik yo rete san seleksyon jiskaske yo verifye match yo.
- Lyen Paryaj Lakay la sèlman parèt apre ou antre yon lyen ou verifye. Pa sèvi ak kòd referans yon lòt moun.
- Paryaj pa garanti revni. Verifye kondisyon legal, laj minimòm ak règleman piblisite anvan monetizasyon.
